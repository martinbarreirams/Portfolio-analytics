**PROYECTO: Web scraping**
La práctica aplica técnicas de web scraping para analizar información financiera de dos organismos estadounidenses. Con datos de la SEC, extrae y compara las carteras declaradas por NFJ Investment Group, SBI Okasan y Banco Santander en sus informes 13F-HR. Con datos de la CFTC, estudia la evolución de las posiciones netas de Asset Managers y Leveraged Money en futuros del NASDAQ MINI. Para ello utiliza en R herramientas como httr y rvest para descargar y extraer datos web, dplyr y readr para limpiarlos y transformarlos, y ggplot2 para resumir y visualizar los resultados.

*Esta carpeta contiene tanto el documento hecho en Quarto como el HTML renderizado.*
