# Portfolio Analytics

Ejercicios prácticos de análisis de datos, hechos como parte de mi proceso de aprendizaje (Business Intelligence & Analytics, Universidad de Valencia).

## Contenido

- **Consultas SQL aplicadas a casos de banca**: casos de negocio de banca resueltos con SQL — JOIN, CTEs, window functions (RANK, AVG OVER) y subconsultas correlacionadas.
- **Análisis del consumo eléctrico en Bélgica | R Markdown**: análisis de series temporales en R sobre el consumo eléctrico de Bélgica (2012-2023).
